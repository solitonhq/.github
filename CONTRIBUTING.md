# Contributing to Soliton

Thank you for helping. This is the default guide for repositories in the Soliton organisation that do not have their own
`CONTRIBUTING.md`; a repository's own guide always takes precedence.

- **Discuss first** for anything non-trivial: open an issue or discussion before a large pull request.
- **Conventional Commits** for messages (`feat:`, `fix:`, `docs:`, `ci:` ...), small and focused.
- **Sign off every commit** with `git commit -s`. This certifies the [Developer Certificate of Origin](https://developercertificate.org/).
- **Keep CI green**: tests, linting and checks must pass before review.
- **Be kind**: everyone follows the [Code of Conduct](CODE_OF_CONDUCT.md).

Found a security problem? Do not open a public issue. See [SECURITY.md](SECURITY.md).
