# Soliton

**Tools shaped by a DevOps engineer's perspective.** Soliton is an engineering philosophy: look at the daily touchpoints of
a DevOps engineer and make each one faster and calmer.

Website: **<https://solitonhq.github.io>** (English and Türkçe)

| Product | What it is | Status |
| --- | --- | --- |
| [**Soliton Rudder**](https://github.com/solitonhq/soliton-rudder) | A fast desktop IDE for Kubernetes: troubleshooting, health checks, topology, cost analysis | Pre-release (macOS) |
| [**Soliton Term**](https://github.com/solitonhq/soliton-term) | An SSH and remote server manager for macOS: Keychain-backed vault, folders, tabs, broadcast and snippets | Pre-release (macOS) |
| **Soliton Pass** | Password manager for people and teams, with a web app and Chrome extension | Planned |
| **Soliton Wiki** | A light, fast wiki for software teams with team-based authorization | Planned |

Soliton Rudder and Soliton Term are open source under the Apache License 2.0; download the latest builds from their releases ([Rudder](https://github.com/solitonhq/soliton-rudder/releases), [Term](https://github.com/solitonhq/soliton-term/releases)). More repositories will appear here as products reach the point where they can be shared.
